# Python tools for FOCUS students

The `astrofocus` package is designed for processing astronomical images as part of the
practical exercises at the FOCUS school, which takes place at *Observatoire de Haute
Provence* (OHP, France).

For now `astrofocus` is not an official package and must be cloned and then imported
manually:

``` python
import sys
sys.path.append("some_dir/astrofocus/src")
import astrofocus
```

where `some_dir` must be set according to where you have cloned this Git repository.
